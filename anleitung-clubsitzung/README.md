# Anleitungsfilm „Clubsitzung vorbereiten und leiten“ – für Klaus (Clubsprecher)

**Datei:** `Clubsitzung-Anleitung-Klaus.mp4` · 1080×1920 (Hochformat, fürs Handy/WhatsApp) · 10:52 Min. · H.264/AAC

Zeigt Schritt für Schritt mit **echten Bildschirmen der Club-App** (Beispieldaten), was der Clubsprecher am Freitagmittag
und am Sitzungsabend tut. Jede Bedienung ist mit einem pulsierenden orangefarbenen Rahmen markiert, der Sprechertext steht als Untertitel darunter.

**In der Club-App (ab 2.738.0, KC-CLUB-FILM-HINWEIS; Fassung mit Brief, „An wen?“ und Freigeben ab 2.741.0):** liegt als `film/clubsitzung-anleitung.mp4`. Wer das Amt **Clubsprecher** hat, bekommt beim
Öffnen der App einmal den Hinweis mit **▶ Film jetzt ansehen** (spielt direkt in der App); jederzeit wieder über Büro → 🎬 Anleitung.
Nach einer neuen Fassung des Films die Datei dort ersetzen.

## Ablauf

1. **Freitagmittag – Sitzung vorbereiten:** Kachel Büro → gelber Zettel „Nächster Schritt: Sitzung vorbereiten“ →
   1️⃣ Wer ist dabei (Zusagen sind angehakt, der Rest wird abends nachgetragen) → 2️⃣ Anmerkung zum letzten Protokoll →
   3️⃣ Tagesordnung (Pfeile, streichen, Vorschläge aufnehmen, eigener Punkt) → 4️⃣ Schreiblinien → Vorschau → „✅ Fertig – speichern“ →
   „📨 Tagesordnung an die Mitglieder senden“ (der Brief mit Vornamen, persönliche Zeile, **An wen?** Alle · Einzeln · Gruppe · Amt, Benachrichtigungsweg, senden) → nur bestimmte Mitglieder anschreiben
   (✒️ Schreiben → Nachricht an Mitglieder → Gruppe, z. B. „Noch ohne Antwort“).
2. **Drucken & Aktentasche:** 🖨️ Drucken → Sitzungs-Vorlage → Druckansicht; 💼 Aktentasche → Anlass → Vorschlag packen →
   Packliste abhaken, Notizen, „Drucken – auswählen“, **📤 Freigeben** (Teile anhaken → An wen? → in den Eingangskorb der Mitglieder;
   so kommt es beim Mitglied an: Hinweis → ansehen → ablegen oder löschen) → „✔ Fertig gepackt“.
3. **Am Abend – Clubabend Live:** Kachel 🍽️ Clubabend Live → Aktentasche, Tagesordnung, ✅ Anwesend (Ampel; Nachzügler antippen) →
   Tagesordnung abhaken → 🗓️ Nächsten Termin abstimmen → 🔴 Live-Abstimmung (alle öffnen die Club-App: Ich kann / Unter Vorbehalt /
   Ich kann nicht; Alternative vorschlagen) → 📅 Termin annehmen → Mitglieder: „In deinen Kalender eintragen?“
4. **Hilfe:** Büro → 📨 Nachricht & Mail → Hansi (Hans-Joachim Koch) → 💬 Nachricht in der App.

Hinweis zur Farbe: In der Club-App ist der Zettel **„Nächster Schritt – Sitzung vorbereiten“ gelb**, der blaue Zettel daneben ist der **Eingang**.
Ab Club-App 2.739.0 wählt man bei der Einladung selbst, **an wen** sie geht (ab 2.741.0: Alle · Einzeln · Gruppe · Amt), ab 2.740.0 ist sie ein
persönlicher Brief („Hallo Marianne, hiermit laden wir dich herzlich …“, Gruß mit Name und Amt).

## Neu erzeugen (`quellen/`)

Voraussetzungen: Node + Playwright (Chromium), ffmpeg, Python mit `piper-tts`, Club-App-Checkout (Stimmmodell + App).

```bash
cd <KC-Clubapp> && python3 -m http.server 8765 &      # Club-App lokal (Server-Aufrufe ersetzt die Aufnahme durch Beispieldaten)
cd anleitung-clubsitzung/quellen
NODE_PATH=$(npm root -g) node teil1.mjs               # Mittag: Büro, Sitzung, Einladung, Drucken, Aktentasche → bild/*.png + szenen-1.json
NODE_PATH=$(npm root -g) node teil2.mjs               # Abend: Clubabend Live, Live-Abstimmung (2 Handys), Hilfe → szenen-2.json
python3 vo.py                                         # Sprecher → ton.wav + zeiten.json (Pfad zum Modell: KC_STIMME)
NODE_PATH=$(npm root -g) node bild.mjs                # film.html Bild für Bild → bild.mp4 (Probe: node bild.mjs probe 10 50)
./mix.sh                                              # Ton + Bild → ../Clubsitzung-Anleitung-Klaus.mp4
```

Texte ändern: `quellen/drehbuch.py` (Szene = Bild + Kapitel + Sprechertext), Bedienfolge: `teil1.mjs`/`teil2.mjs`
(`bild(seite, name, ring)` nimmt ein Bild auf und merkt sich den Rahmen um das angetippte Element).
